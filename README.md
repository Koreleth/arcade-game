# 🎮 Arcade Game

Ein lokales 2-Spieler-Arcade-Spiel, inspiriert von klassischen Bomberman-Mechaniken.  
Ziel ist es, durch geschicktes Platzieren von Bomben den Gegner auszuschalten, Kisten zu sprengen und versteckte Items zu finden.

## 🎮 Spielanleitung

**Spielmodus:** Lokales 2-Spieler-Spiel  
**Steuerung:** Tastatur  

Beide Spieler starten an festen **Spawnpunkten**.  
Ziel ist es, mit Bomben Kisten zu zerstören und den Gegner zu besiegen.  
Unter den zerstörten Kisten können sich Items verstecken, die verschiedene Fähigkeiten verleihen.

### 🔹 Items

1. **🛼 Rollerblades** – Erhöhen die Bewegungsgeschwindigkeit  
2. **💣 Bomben-Multiplikator** – Erhöht die Anzahl gleichzeitig platzierbarer Bomben  
3. **🔥 Bomben-Radius** – Erweitert die Explosionsreichweite der Bomben

## 🚀 Startanleitung

1. Lade alle Projektdateien herunter.  
2. Starte folgende Dateien in der jeweiligen Software:

   - 🎵 **Audio:** `sounds/soundmixer.maxpat` (in *Max 8*)  
   - 💥 **Spiel:** `java/Bomberman.pde` (in *Processing*)
